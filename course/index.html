LangChain Agent Kursu

Junior developer icin uygulamali kurs. Anlatim Turkce, terimler Ingilizce. Her sorunun cevabi ayni sayfada, baskida ayri sayfada durur. Her kod ornegi labs/ altinda calisan bir programdir; sayfadaki kod ile dosya aynidir.

Nasil calistirilir

  1. Python 3.12 kurulu olsun. Bu kurs 3.12 sanal ortami kullanir.
  2. Proje kokunde: py -3.12 -m venv .venv
  3. .\.venv\Scripts\python.exe -m pip install -e ".[dev]"
  4. .env.example dosyasini .env olarak kopyalayin. Icine gercek anahtar yazmayin.
  5. Ollama calissin. Iki yerel model indirilir: ollama pull gemma3:4b ve ollama pull qwen2.5:3b. Gemma duz metin lablarindadir. Bu Ollama surumu gemma3:4b ile tool calling kabul etmez. Agent lablarinda Qwen 2.5 3B kullanilir.
  6. Bir lab: .\.venv\Scripts\python.exe labs\ch01\summarize_chain.py
  7. Testler: .\.venv\Scripts\python.exe -m pytest

Ucretli OpenAI, LangSmith veya Tavily anahtari gerekmez. Duz metin Gemma 3 4B ile, tool calling Qwen 2.5 3B ile calisir. Bulut servisleri istege bagli degisim olarak anlatilir.

Nasil yazdirilir

Tum kurs tek dosyadadir: print.html. Onu tarayicide acin ve yazdirin. Kagit A4, kenar bosluklari varsayilan. Kod renkleri yazi rengidir; arka plan grafikleri kapali olsa da anahtar kelime, string ve yorum ayri renk kalir. Uzun kod bir sonraki sayfaya taser. Cevap anahtari her dersin sonunda yeni sayfadan baslar.
