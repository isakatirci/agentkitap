Chapter 1 — LangChain Foundations

Bu bolum bir agent yazmaz. Agent'tan once duran uc parcayi kurar: ayar dosyasi, prompt template ve chat model. Bunlar bir chain icinde birbirine baglanir. Sonra ayni chain yerel Gemma modeline tasinir ve her model cagrisi bir trace satirina yazilir.

Bu bolumun sonunda su isleri tek basiniza yapabilirsiniz: .env dosyasindan MODEL okumak, bir metni ChatPromptTemplate ile tek cumleye ozetlemek, donen nesnenin AIMessage oldugunu gorup content alanini almak, ayni chain'i baska bir chat model ile calistirmak ve o cagriyi yerel trace'e yazmak.

1. Proje, ortam ve gizli degerler

environment variable
Isletim sisteminin programa verdigi isimli deger. Kodun icine sifre yazmak yerine bu isimler okunur.

Environment variable listesini tutan yerel dosya. Git'e girmez.

Ikinci hata, anahtari hic ayirmadan "bende calisiyor" deyip baska bilgisayarda ayni kodun neden durdugunu anlamamaktir. Ayar bir isimdir. Kod o ismi okur. Deger makinede kalir.

Bu kurs ucretli bir anahtar istemez. Yine de aliskanlik ayni olsun. .env.example sadece isimleri gosterir: MODEL, LANGSMITH_TRACING, TAVILY_API_KEY. Gercek .env kopyasidir ve .gitignore icindedir. Bos birakilan Tavily satiri, "bu isim var, degeri yok, lab onu kullanmiyor" demektir.

Python paketleri proje klasorune degil, sanal ortama kurulur. py -3.12 -m venv .venv komutu 3.12 yorumlayicisina ait bir .venv klasoru acar. Kurs 3.12 ister cunku LangChain tekerlekleri bu surumde saglamdir. Komutlar .venv\Scripts\python.exe ile calisirsa sistemdeki Python 3.14 karismaz.

Kod bicimi de ayarin parcasidir. Black veya Ruff, satir uzunlugunu ve bosluklari sizin yerinize duzeltir. Mantigi degistirmez. Bu bolumdeki lablar zaten o duzende yazilidir: bir fonksiyon bir is yapar, isimler Ingilizce, yorumlar Turkce. Bicim araci "neden" sorusunu cevaplamaz; "goz yorulmasin" diye vardir.

Asagidaki program python-dotenv paketindeki dotenv_values fonksiyonunu kullanir. Dosyayi okur, yorum satirini atlar, sozluk dondurur. Ortam degiskenlerini sessizce degistirmez. Test, gercek makinenizdeki MODEL degerine bagli kalmaz.

Calistirma: .\.venv\Scripts\python.exe labs\ch01\load_env.py

Beklenen cikti: MODEL=gemma3:4b

"""Ortam degiskenlerini kod icinde okumak.

Junior notu: API anahtari ve model adi koda yazilmaz. .env dosyasinda durur,
kod sadece isimleri okur. .env git'e girmez; .env.example girer.
"""

from pathlib import Path

from dotenv import dotenv_values


def load_settings(path: str) -> dict[str, str]:
    """KEY=VALUE dosyasini sozluge cevir.

    dotenv_values yorum satirlarini (#) ve bos satirlari atlar.
    Dosyayi islem ortamina yazmaz; sadece sozluk dondurur.
    Boylece testler gercek ortam degiskenlerini kirletmez.
    """

    # Path, Windows ve ders klasoru icin ayni sekilde calisir.
    env_path = Path(path)
    # Donen degerler str veya None olabilir. None olanlari almuyoruz.
    raw = dotenv_values(env_path)
    # Bos degerler None gelebilir. Onlari sozluge koymayiz.
    settings: dict[str, str] = {}
    for key, value in raw.items():
        if value is None:
            continue
        settings[key] = value
    return settings


def main(env_path: str = ".env.example") -> dict[str, str]:
    """Ornek dosyayi okuyup MODEL anahtarini gosterir."""

    # .env.example gercek anahtar tasimaz. Sadece isimleri gosterir.
    settings = load_settings(env_path)
    # MODEL, ChatOllama'ya verilecek yerel model adidir.
    print(f"MODEL={settings.get('MODEL', '')}")
    return settings


if __name__ == "__main__":
    main()

2. Prompt template, chat model ve chain

prompt template
Icinde {text} gibi bosluklar olan kalip. Calisma aninda dolar.
chat model
Mesaj listesi alip assistant mesaji donduren model. Bu kursta ChatOllama.
chain
Bir adimin ciktisini sonraki adimin girdisi yapan boru.
LCEL
LangChain Expression Language. Baglantiyi | ile yazarsiniz.

Bir prompt, modele giden metindir. Ayni metni her seferinde tirnak icinde birlestirmek ise junior kodunu kirilgan yapar. Unvan degisir, dil degisir, kullanici metni tirnak icinde tirnak bozar. Prompt template kalibi ayri tutar. Bosluklar veri, cumleler talimattir.

ChatPromptTemplate.from_template tek bir human mesaji kurar. Sablon soyle durur: "Summarize the text in one sentence." Ardindan Text: ve {text}. invoke({"text": paragraf}) cagrisi boslugu doldurur. Model ham paragrafi gormez. Doldurulmus mesaji gorur. Bu ayrim onemlidir. Hata ayiklarken "ben bunu gondermistim" demeden once, template'in urettigi mesaji okuyun.

Chat model bir fonksiyon gibi durur ama duz string dondurmez. Girdi bir mesaj listesidir. Cikti bir AIMessage nesnesidir. LangChain bu nesneyi tum saglayicilarda ayni sekilde tutar. Ollama da, ileride bakacaginiz bulut model de ayni invoke sozunu tutar. Bu yuzden ders kodu model parametresi alir. Test, scriptli bir FakeChatModel verir. Siz komutu dogrudan calistirirsaniz make_chat_model() yerel gemma3:4b modelini, temperature=0 ile acar.

temperature rastgeleligi ayarlar. 0, ayni soruya daha kararli cevap demektir. Yaratici yazida yukseltilir. Ozet ve agent icin 0 birakilir ki bugun calisan ornek yarin bambaaska cumle kurmasin. num_predict ise cevabin uzunlugunu keser. Kesilmezse kucuk bir model sayfalarca yazar ve lab donmus gibi durur. Yine de model bir insan degildir; 0 bile kelimesi kelimesine garanti vermez. Testler bu yuzden canli modelin cumlesini kilitlemez. Scriptli model kilitlenir.

Chain, bu iki adimin adidir. LCEL'de prompt | model okunusu sudur: once prompt calissin, ciktisi modele gitsin. Siz ara sonucu elle tasimazsiniz. Ozet labi tam olarak bu borudur.

3. Metin ozeti

Ilk gercek is, kisa bir paragrafi tek cumleye indirmektir. Chain'e sozluk verirsiniz. Anahtar, template'teki isimle ayni olmalidir: text. Donus degeri metin degildir. summarize fonksiyonu content alanini stringe cevirip dondurur. Boylece cagiran taraf nesne tasimaz.

Neden tek cumle? Cunku ilk labda olcum kolay olsun. "Ozet iyi mi" sorusu ayri bir derstir. Burada soru sudur: metin modele gitti mi, content geri geldi mi? Scriptli test her ikisini de bakar. Canli Gemma calistirilirsa cumle Ingilizce ve kisa olur; talimat Ingilizcedir, model talimati izler.

Calistirma: .\.venv\Scripts\python.exe labs\ch01\summarize_chain.py

Beklenen: Python'un yeni baslayanlar icin bir dil oldugunu soyleyen tek cumle. Cumle her calistirmada ayni kelimeler olmayabilir. Bos cikti bir hatadir.

"""Prompt template ve chain ile metin ozeti.

Bir chain, bir adimin ciktisini sonraki adima verir.
Burada ilk adim prompt template, ikinci adim chat modeldir.
LCEL'de bu baglanti | operatoru ile yazilir.
"""

from langchain_core.messages import AIMessage
from langchain_core.prompts import ChatPromptTemplate

from labs.kit.models import make_chat_model


def build_summarize_chain(model):
    """Tek cumlelik ozet isteyen chain.

    {text} bir bosluktur. invoke sirasinda gercek metin oraya yapisir.
    Model ham metni degil, bu kalibin doldurulmus halini gorur.
    """

    # from_template, tek bir human mesaji ureten prompt template kurar.
    prompt = ChatPromptTemplate.from_template(
        "Summarize the text in one sentence.\n\nText:\n{text}"
    )
    # | operatoru: once prompt calisir, ciktisi modele gider.
    return prompt | model


def summarize(text: str, model) -> str:
    """Metni chain'den gecirip modelin content alanini dondurur.

    invoke sozlugu, template icindeki {text} boslugunu doldurur.
    Chat model bir AIMessage dondurur. Junior'in okumasi gereken
    alan content'tir; nesnenin kendisi duz yazi degildir.
    """

    # Chain'i her cagri kurmak, prompt ile modeli yan yana tutar.
    chain = build_summarize_chain(model)
    # Sozluk anahtari, template icindeki {text} adiyla ayni olmalidir.
    message = chain.invoke({"text": text})
    # Bazi chain'ler duz str dondurebilir. Bu kurs chat model kullandigi
    # icin beklenti AIMessage'tir. Yine de str gelirse onu oldugu gibi alin.
    if isinstance(message, str):
        return message
    if not isinstance(message, AIMessage):
        return str(message.content)
    return str(message.content)


def main(model=None) -> str:
    """Kucuk bir paragrafi ozetler. model verilmezse yerel Gemma kullanilir."""

    source = (
        "Python is a programming language used by beginners. "
        "It reads like English and is common in automation."
    )
    chosen = model or make_chat_model()
    summary = summarize(source, chosen)
    print(summary)
    return summary


if __name__ == "__main__":
    main()

4. Response nesnesini okumak

AIMessage
Modelin dondurdugu mesaj. Metin content icindedir. Arac istegi tool_calls icindedir.

Konsola print(message) yazarsaniz uzun bir nesne gorursunuz: id, ek alanlar, bos tool listesi. Ozet o ciktirmanin tamami degildir. Junior'in bakacagi uc alan vardir.

  • type degeri ai ise bu bir model cevabidir. Kullanici mesaji human olur.
  • content gosterilecek metindir. Bos string, modelin bu turda yazi yerine arac istemis olabilecegi anlamina gelir. Chapter 2'de bunu goreceksiniz.
  • tool_calls bos liste ise model arac istememistir. Doluysa her oge bir ad, bir arguman sozlugu ve bir id tasir.

Asagidaki lab modele gitmez. Elle bir AIMessage kurar ve uc alani sozluge koyar. Amac, canli model kosturmadan nesnenin sekline alis manizdir. Gercek ozet labinda donen sey de bu siniftandir.

Calistirma: .\.venv\Scripts\python.exe labs\ch01\read_response.py

Beklenen: type alani ai, content dolu, tool_calls bos liste.

"""Model cevabini nesne olarak okumak.

Junior'lar siklikla print(response) yapip tum nesneyi cumle sanir.
Asil metin content alanindadir. tool_calls bos ise model arac istememis demektir.
"""

from langchain_core.messages import AIMessage


def describe_response(message: AIMessage) -> dict:
    """AIMessage icinden junior'in bakacagi uc alani cikarir.

    type: mesajin rolu. Model cevabinda bu deger "ai" olur.
    content: kullaniciya gosterilecek metin.
    tool_calls: model bir tool istiyorsa burasi dolu olur. Chapter 2'de kullanilir.
    """

    # type, mesajin roludur. Model cevabinda bu deger "ai" olur.
    # content, kullaniciya basacagin metindir. print(message) bu metin degildir.
    # tool_calls bos ise model bu turda bir tool istememistir.
    return {
        "type": message.type,
        "content": message.content,
        "tool_calls": list(message.tool_calls),
    }


def main() -> dict:
    """Elle kurulmus bir AIMessage ile alanlari yazdirir.

    Bu dosya modele gitmez. Amac, response nesnesinin şeklini gormektir.
    """

    # Canli modele gitmeden response seklinin ornegi.
    sample = AIMessage(content="Python is beginner friendly.", tool_calls=[])
    # Sozluk, uc alani yan yana gosterir.
    info = describe_response(sample)
    print(info)
    return info


if __name__ == "__main__":
    main()

5. Yerel open-weight model: Ollama ve Gemma

open-weight model
Agirliklari indirip kendi makinenizde calistirabildiginiz model. Bu kursta Gemma 3 4B.
Ollama
Yerel modeli bir HTTP servisi gibi sunan program. LangChain tarafi ChatOllama sinifidir.

Kitaptaki ornekler siklikla bulut modeliyle baslar, sonra ayni kodu Ollama'ya tasir. Bu kursta sira tersine cevrildi cunku dogrulanan yol ucretli anahtar istemez. Fikir aynidir: chain degismez, chat model degisir.

make_chat_model() su an ChatOllama(model="gemma3:4b", temperature=0) dondurur. Ollama servisi 127.0.0.1:11434 adresinde dinler. Model yoksa ollama pull gemma3:4b indirir. Indirme bir kez yapilir. Bu Ollama surumu gemma3:4b ile tools listesini reddeder. Tool calling bolumleri bu yuzden make_tool_model() ile qwen2.5:3b kullanir. Ikisi de yereldir.

Baska bir modele gecmek fabrikada model adini degistirmektir. Uygulama fonksiyonu main(model=None) seklindedir. Arguman bos ise fabrika calisir. Test, ayni fonksiyona scriptli model verir ve "Local summary." metnini bekler. Yani siz Gemma'nin cumlesini ezberlemezsiniz. Kod yolunun calistigini, canli calistirmada da bos olmayan bir ozet geldigini gorursunuz.

Calistirma: .\.venv\Scripts\python.exe labs\ch01\swap_model.py

Beklenen: yerel modelin tek cumlelik ozeti. Servis kapaliysa baglanti hatasi alirsiniz. Once ollama serve calismalidir.

"""Ayni chain, farkli chat model.

Uygulama kodu modelin nereden geldigini bilmemeli.
make_chat_model() varsayilan olarak yerel Gemma dondurur.
Testler ayni main() fonksiyonuna FakeChatModel verir.
Bulut modeline gecmek, bu fabrikada tek satiri degistirmektir.
"""

from langchain_core.prompts import ChatPromptTemplate

from labs.kit.models import make_chat_model


def summarize_with(model, text: str) -> str:
    """Chapter 1 ozet chain'inin modelden bagimsiz hali.

    Prompt ayni kalir. Degisen sadece invoke edilen chat modeldir.
    """

    # Kalip ayni kalir. Degisen sey yalnizca asagidaki modeldir.
    prompt = ChatPromptTemplate.from_template(
        "Summarize the text in one sentence.\n\nText:\n{text}"
    )
    # | once prompt'u doldurur, sonra modeli cagirir.
    chain = prompt | model
    message = chain.invoke({"text": text})
    # content, AIMessage icindeki gosterilecek metindir.
    return str(message.content)


def main(model=None) -> str:
    """model None ise Ollama Gemma, degilse verilen model kullanilir."""

    source = "Local open-weight models can run on your own machine."
    # Test FakeChatModel verir. Bos birakilirsa yerel Gemma acilir.
    chosen = model or make_chat_model()
    summary = summarize_with(chosen, source)
    print(summary)
    # Test bu stringi scriptli modelin content'i ile kilitler.
    return summary


if __name__ == "__main__":
    main()

6. Trace: ne gitti, ne dondu

trace
Bir chain veya agent calismasinin adim gunlugu. Hangi prompt gitti, model ne dedi, varsa hangi tool calisti.
LangSmith
Bu gunlugun buluttaki ekrani. LANGSMITH_TRACING=true ve bir API anahtari ister. Kurs onsuz da ayni olayi yerel yazar.

Ozet yanlis cikinca junior genellikle talimati bastan yazar. Once trace'e bakmak daha ucuzdur. Soru uc tanedir. Template gercekten kullanici metnini yapistirdi mi? Model o metne cevap mi verdi, yoksa bos mu dondu? Kac kez cagrildi?

Bu labda tek bir chain vardir, tool yoktur. Trace'te tam bir llm olayi gorursunuz. Prompt alaninda sizin verdiginiz metin, response alaninda content vardir. Chapter 2'de ayni gunluge tool satiri girecek. Sira soyle olacak: llm, tool, llm. O sira, agent'in "dusun, arac kullan, sonucu gor, cevapla" dongusudur. Simdilik tek satir yeter.

LangSmith acilirsa ayni kosu orada da gorunur. Proje adi .env.example icinde agent-course olarak durur. Anahtar yokken kutuphane izi yerel birakmak zorunda degildir; biz izi kendimiz LocalTracer ile yaziyoruz. Iki ekran ayni soruya cevap verir: bu calismada model kac kez konustu?

Calistirma: .\.venv\Scripts\python.exe labs\ch01\trace_chain.py

Beklenen: once ozet cumlesi, sonra icinde tek kind: llm olan bir liste.

"""Chain calismasini yerel trace'e yazmak.

LangSmith ayni fikrin bulut ekranidir: hangi prompt gitti, model ne dedi.
Bu lab hesap acmadan ayni olayi LocalTracer icine yazar.
"""

from langchain_core.prompts import ChatPromptTemplate

from labs.kit.models import make_chat_model
from labs.kit.tracer import LocalTracer


def traced_summarize(text: str, model, tracer: LocalTracer) -> str:
    """Ozet uretir ve tek bir llm olayi kaydeder.

    prompt alanina kullanicinin verdigi metin yazilir ki izde
    'modele ne sorduk' gorulsun. response, modelin content degeridir.
    """

    # Ozet chain'i Chapter 1 ile aynidir. Eklenen sey tracer kaydidir.
    prompt = ChatPromptTemplate.from_template(
        "Summarize the text in one sentence.\n\nText:\n{text}"
    )
    # Pipe, promptu modele baglar. Ara degisken tutulmaz.
    message = (prompt | model).invoke({"text": text})
    answer = str(message.content)
    # Trace, chain bittikten sonra da okunabilsin diye ayri nesnededir.
    tracer.record_llm(prompt=text, response=answer)
    return answer


def main(model=None) -> str:
    """Bir ozeti calistirir ve trace satirini yazdirir."""

    # Yeni bir gunluk. Onceki labin olaylari buraya karismaz.
    tracer = LocalTracer()
    chosen = model or make_chat_model()
    answer = traced_summarize("Tracing shows each model call.", chosen, tracer)
    print(answer)
    # Tek olay beklenir: kind degeri llm.
    print(tracer.events)
    return answer


if __name__ == "__main__":
    main()

Cevap anahtari

Cevap 1. .env makineye ozel deger tasir: model adi, iz anahtari, ileride eklenecek ucretli anahtar. Depoya girerse anahtar gecmis commit'lerde kalir. .env.example sadece isimleri gosterir, degerleri bos veya ornek birakir. Cevap 2. Ayni sey degildir. Template kaliptr. Doldurulmus prompt, kalibin {text} yerine paragraf yapismis halidir. Modele giden metin paragrafin aynisi degildir. Onunde "Summarize the text in one sentence." talimati vardir. Hata ayiklarken model.calls veya trace'deki prompt alanina bakin, kendi degiskeninize degil.

Cevap 3. | once soldaki runnable'i calistirir, ciktisini sagdakine verir. Solda prompt template mesaj listesi uretir. Sagda chat model o listeyi AIMessage yapar. Elle tasimak ayni isin daha uzun ve daha kolay bozulan halidir. Chain buyuyunce (ciktiyi bicimlemek, ikinci bir adim eklemek) boruya yeni bir halka eklersiniz.

Cevap 4. print(response) tum nesneyi basar: tip, id, ek alanlar. Gosterilecek metin content alanidir. tool_calls bos liste ise model bu cevapta bir tool istememistir. Dolu olsaydi content bos kalabilir ve asil istek arac listesinde dururdu. Ozet labinda liste bostur cunku talimat yazi ister.

Cevap 5. temperature uretimin rastgeleligini ayarlar. 0, daha kararli cevap icindir. Kararlılik, ayni cumlenin kilitli oldugu anlamina gelmez. Canli model her calistirmada es anlamli baska bir cumle kurabilir. Test, scriptli modelde tam metni kilitler. Canli smoke test ise cumlenin bos olmadigina ve kaynak metnin gonderildigine bakar.

Cevap 6. Bir llm olayi vardir. Tool yoktur, ikinci bir model cagrisi yoktur. Bilgi LocalTracer.events listesindedir. LangSmith ayni kosunun bulut kopyasidir. Anahtar yokken yerel liste yeter.

Cevap 7. Talimat cumlesi "three bullet points" ister. Chain yine prompt | model seklindedir. Bu hala serbest metindir, alanlari olan bir nesne degildir. Structured output Chapter 2'dedir.

"""Uygulama cevabi: ozeti uc madde olarak iste.

Soru: summarize_chain.py icindeki talimati degistir.
Modelden tek cumle degil, tam olarak uc madde iste.
Asagidaki prompt bu degisikligin tam halidir.
"""

from langchain_core.prompts import ChatPromptTemplate

from labs.kit.models import make_chat_model


def summarize_as_bullets(text: str, model) -> str:
    """Ayni chain deseni, farkli talimat.

    'three bullet' ifadesi talimatin parcasi olarak modele gider.
    Model yine serbest metin dondurur; madde isareti istemek sema degildir.
    Sema Chapter 2 structured output konusudur.
    """

    # "three bullet" talimati modele giden metnin parcasi olur.
    prompt = ChatPromptTemplate.from_template(
        "Summarize the text as three bullet points.\n\nText:\n{text}"
    )
    # Chain yine prompt, sonra modeldir. Tek cumlelik labdan farki bu satirdir.
    message = (prompt | model).invoke({"text": text})
    # Donen sey hala serbest metindir, Pydantic nesnesi degildir.
    return str(message.content)


def main(model=None) -> str:
    source = "Python, tests, and agents help a junior ship small programs."
    # model verilmezse Gemma kullanilir. Test scriptli model gecirir.
    chosen = model or make_chat_model()
    answer = summarize_as_bullets(source, chosen)
    print(answer)
    # Madde isaretleri modelden gelir. Kod onlarin yerini zorlamaz.
    return answer


if __name__ == "__main__":
    main()
