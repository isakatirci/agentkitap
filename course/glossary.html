Kurs Glossary

Glossary

Terimler Ingilizce kalir. Buradaki cumle her terimin ilk karsiligidir.

prompt
Modele verilen metin. Model bundan sonraki tokenlari uretir.
prompt template
Icinde bosluklar olan prompt kalibi. Bosluklar calisma aninda dolar.
chat model
Mesaj listesi alip bir assistant mesaji donduren model.
chain
Bir adimin ciktisini sonraki adima veren boru. Bu kursta prompt, sonra model.
LCEL
LangChain Expression Language. | ile adimlari birbirine baglar.
AIMessage
Modelin dondurdugu mesaj nesnesi. Metin content alanindadir.
tool
Modelin kendi basina yapamadigi isi yapan fonksiyon: arama, dosya, hesap.
tool calling
Modelin "su fonksiyonu su argumanlarla cagir" diye yapilandirilmis istek uretmesi.
agent
Model ile tool arasinda, is bitene kadar donen dongu.
ReAct
Reason and Act. Thought, action, observation adimlariyla dusunen agent deseni.
thought
Modelin bir sonraki adimi neden sectigini yazdigi satir.
action
Cagrilacak tool ve argumanlari.
observation
Tool calistiktan sonra donguye geri yazilan sonuc.
scratchpad
Onceki thought, action ve observation metinlerinin biriktigi alan.
structured output
Serbest cumle yerine belirli alanlari olan nesne. Bu kursta Pydantic modeli.
Pydantic
Python sinifini hem belge hem dogrulama semasina ceviren kutuphane.
ProviderStrategy
Structured output'u modelin kendi sema destegiyle alma yolu.
ToolStrategy
Structured output'u ozel bir tool cagrisi gibi alma yolu.
JSON schema
Bir tool'un adini, aciklamasini ve arguman tiplerini anlatan JSON.
stop sequence
Modelin uretimini durduran metin parcasi.
zero-shot
Ornek vermeden sadece talimatla sormak.
few-shot
Promptun icine birkac cozulmus ornek koymak.
chain of thought
Modelden once ara adimlari yazmasini istemek.
context window
Modelin bir cagrida gorebildigi metin kapasitesi.
context engineering
O pencereye neyin girip neyin disarida kalacagini tasarlamak.
shallow agent
Kisa, tek duzeyli tool dongusu. Uzun islerde dagilir.
deep agent
Plan, alt agent ve dosya kullanabilen uzun is harness'i.
harness
Modelin etrafindaki duzen: prompt, tool'lar, dongu ve sinirlar.
subagent
Ana agentin bir alt gorev icin calistirdigi ayri dongu.
system prompt
Kullanici mesajindan once duran, rolu ve kurallari yazan metin.
prompt injection
Dis metnin, system prompt kurallarini ezmeye calismasi.
supply chain
Agentin cagirdigi paket, tool ve sunucularin guven zinciri.
MCP
Model Context Protocol. Dis bir sunucunun araclari modele acmasinin standart yolu.
sandbox
Agentin dosya yazabildigi sinirli klasor. Proje kokune yazamaz.
